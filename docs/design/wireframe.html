Scope — UX Wireframe (MVP)

Five screens tracing the core flow: sign in → create term → upload syllabus → review + approve → land on a dashboard where every uploaded course now lives as data you can refer back to. Low-fidelity on purpose — annotate any box, label, or copy you want changed.

Decisions locked from this review

Decided Auth

Google OAuth as the sign-in path

Supabase Auth + Google provider replaces email/password. Allowlist checks the Google account email. Google Cloud Console + OAuth consent screen still needs captain hands-on-browser setup — see the OAuth prep guide committed to the repo.

Decided Approval

Summary line stays, expand becomes prominent

Glance-level summary confirmed. Each series row shows expand as a primary action so individual items are always one click from inspection.

Decided Dashboard

Land on Today for MVP

Always route the signed-in user to Today. "Remember last view" deferred to post-MVP once we know if users actually roam between views.

Decided Today

"Start tonight" promoted to hero banner

Now the first thing users see on Today. Gold gradient + primary "Open" action, still wireframe-clean, still one focused suggestion.

Design: Lavish-recommended Tailwind v4 + DaisyUI v5 (luxury theme), plus custom monochrome wireframe styling. Reason: scope-app has no code yet, so no product design system exists to match.
