Status pill. Used for `Step 1 of 3`, item types, magnitude, and `needs_review` confidence flags.

```jsx
<Badge pill tone="accent">Step 1 of 3</Badge>
<Badge tone="warn">Scope wasn’t sure</Badge>
<Badge mono>mag 3</Badge>
```

Never more than one gold `accent` badge in a row of badges — gold means "the thing to act on".
